# case/

Fusion 360 source (`.f3d`), exports (`.step`), print files (`.stl` / `.3mf`) and print notes for
the wearable case. Design constraints, the two candidate envelopes and the feature list are in
`docs/03-hardware.md` §5. Decisions to record in `docs/DECISIONS.md` before printing five:

- band-width family (38–42 mm stacked vs 44–49 mm single-layer),
- IMU orientation (arrow toward the elbow, X along the forearm),
- lid retention (snap-fit lip vs M2 heat-set inserts).

Caliper the real parts before finalizing; the BOM dimensions are nominal.
